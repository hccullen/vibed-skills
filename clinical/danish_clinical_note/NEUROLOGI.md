# Specialty Reference: Neurologisk Journaloptagelse

Specialty-specific journal template for neurological admissions. Sourced from [Neurologisk Journaloptagelse V12](https://viborgneuro.dk/wp-content/uploads/2025/03/Neurologisk-journaloptagelse_V12.pdf) (Viborg Neurology, March 2025).

The neurological journaloptagelse has a fixed structure that goes beyond PSOAP — it adds specific symptom checklists, a systematic neurological examination, and standardised assessment scores.

## Structure

### Stamoplysninger

| Field | Content |
|---|---|
| Lokale / Navn / Spgl. / Tlf. | Patient and referring physician |
| RF / Sat / BT / P / Tp | Referral date, saturation, blood pressure, pulse, temperature |

### Anamnese

**Kontaktårsag:** The presenting complaint in one line.

**Dispositioner:** Predisposing factors — noted when suspecting e.g. struma, hearing loss.

**Ekspositioner:** Exposures — noted when suspecting e.g. mononukleose, cancer, noise exposure.

**Cerebrovaskulære risikofaktorer:** HT, hyperkolesterol, TCI/stroke, rygning, alkoholoverforbrug, DM, AFLI, cancer m.fl.

**Aktuelt — symptom checklist:**
- Kraft, styring, facialisparese, føleforstyrrelser, tale, syn, balance, gang, synkebesvær
- Hovedpine, NRS, fotofobi, petekkier, kvalme/opkast, svimmelhed, besvimelse
- Kramper, trækninger, tungebid, inkontinens

**Almen symptomer:** Feber, vægttab, smerter, søvn, nattesved, hudkløe.

**Øvrige organsystemer** (kort, relevant):
- **CNS:** se aktuelle
- **CP:** brystsmerter, hjertebanken, hoste, ekspektorat, åndenød (hvile/funktion), ødemer
- **GI:** mavesmerter, kvalme, opkastninger, appetit, synkesmerter, vægttab, sure opstød, halsbrand, afføringsændringer (diarré, obstipation, blod, slim)
- **UG:** kløe, svie, smerte, urin, blod/skum, hyppighed, inkontinens, igangsætnings/tømningsbesvær
- **BVA:** muskel-/ledsmerter, udslæt

**Medicin:** Præparatnavn, styrke, dosis.

**Socialt:**
- Boligforhold
- Samlever
- Funktionsniveau
- Erhverv (tidl. eller aktivt)
- Kørsel / bil
- CAVE [morfin, penicillin, plaster, kontrast]
- Vægt / Højde / Implantater (nej/ja)

**KRAM-faktorer:**
- Kost / motion
- Rygning: Aldrig røget / eks ryger / ryger dagligt / ryger lejlighedsvist / tobak pr. døgn / røget antal år / alder ved rygestart
- Alkohol: Uoplyst / intet forbrug / nuværende antal genstande / >10 gst. ugentligt

**Tidl. kendt med:** Previous diagnoses listed.

### Objektivt

**Generelt:** AT (akut/kronisk), ET, farver, respiration, stemme.

**Systematic examination:**

| System | What to document |
|---|---|
| Cavum oris | Ingen akutte forandringer, god tandstatus, ingen tonsilhypertrofi |
| Collum | Ingen struma eller halsvenestase |
| Lymfeknuder | Ingen lymfadenit subman, langs SCM, periclavikulært — eller submen, axil, inguinalt |
| St. p | Vesikulær respiration bilat., uden bilyde |
| St. c | Regelmæssig hjerteaktion = pp, ingen hørbare mislyde |
| Abdomen | Blødt, fladt og indolent / slipømhed / indirekte ømhed / defence, tarmlyde, nyreloger, megali |
| Hud | (document findings) |
| Suppl. [TOKS-værdier] | (document values) |

**Neurologisk undersøgelse:**

**Mentalt:** Vågen og orienteret. Ingen NRS (Nyere Roskilde Sprogskala).

**Tale:** Ingen afasi eller dysartri.

**Kranienerver:** Bevaret syn og synsfelt med egale pupiller og normale øjenbevægelser uden nystagmus. Normal ansigtssensibilitet, normal mimik.

**Gang og stand:** Normal stand og gang med åbne og lukkede øjne.

**Motorisk system:** Ingen atrofi, normal tonus. Strakt arm og bentest uden nedsynkning/pronation. Normal kraft over:
- Skulder, Albue, Håndled, Fingre (flektion/add, ekstension/abd)
- Hofte, Knæ, Fod

**Reflekser:** Normale biceps-, triceps-, brachioradialis-, patellar- og achilles-reflekser. Plantarresponset normalt (plantarflektion / no-respons / afværge) eller ekstensivt.

**Cerebellare system:** Normal koordination ved FNF- (finger-næse-finger) og KH- (knæl-hæl) forsøg, dysdiadokokinese.

**Ekstrapyramidale system:** Ingen bradykinesi, rigiditet eller ufrivillige bevægelser.

**Sensoriske system:** Normal sensibilitet for berøring og stik bilateralt. Ingen sensibilitetsgrænse på truncus. OE / UE.

**Andre:** Neglekt. Apraksi. NIHSS-score.

### Vurdering af prøver og undersøgelser

Document findings from: Neurologisk us (inkl. NIHSS) | Værdier | EKG | MR/CT | UL | Biokemi | Suppl.

### Vurdering / Konklusion

Format: *"X-årig X, kendt med [tidl. diagnoser]. Ses i dag i X grundet episode d. [dato]. Aktuelt findes: [clinical findings]. Vurderes: [assessment]. Konfereret med: [name/title if applicable]."*

### Plan

Ordinationer, TOKS/SSS, further investigations, follow-up.

### Informeret samtykke

Inkl. evt. indikation for medicin, mulige bivirkninger og opfølgning.

### Checklist (Husk ved alle journaler)

1. **Cave** — document allergies / Metalskema / Telemetri / Holter
2. **Sygdomshistorik** — FMK (ajourført?) / Kørselsforbud
3. **Medicin** — godkendt / Diagnose(r) registreret

## Key Terminology

| Danish | English | Context |
|---|---|---|
| NRS | Nyere Roskilde Sprogskala | Danish stroke scale (analogous to NIHSS) |
| NIHSS | NIH Stroke Scale | Used alongside NRS |
| FNF | Finger-næse-finger | Cerebellar coordination test |
| KH | Knæl-hæl | Cerebellar coordination test |
| Strakt arm test | Arm holding test | Motor screening for pronator drift |
| Bentest | Leg holding test | Motor screening for lower limb weakness |
| TOKS | (Toxikologisk screen) | Toxicology screen |
| SSS | (Scandinavian Stroke Scale) | Stroke assessment scale |
| AT | Almentilstand | General condition |
| ET | Ernæringstilstand | Nutritional status |
| St. p | Status pulmonalis | Pulmonary examination |
| St. c | Status cordis | Cardiac examination |
| pp | Pure/percussion | Heart action description |
| CAVE | (Latin: cave) | Allergies/intolerances to document |
