# Specialty Reference: ØNH (Øre-, Næse- og Halskirurgi) Journaloptagelse

Specialty-specific journal template for ENT (ØNH) admissions. Sourced from [Journalvejledning for læger – ØNH afdelingen](https://pri.rn.dk/Sider/29696.aspx) (Region Nordjylland, Aalborg Universitetshospital, effective 08/07/2026).

The ØNH journaloptagelse uses a structured anamnese/objektivt format with organ-specific symptom mapping. The examination is organised by anatomical region, and the presenting symptom determines which additional symptoms to document.

## Generelle forhold

- Præsentér jer selv
- Håndhygiejne
- Tavshedspligt

## Anamnese

| Section | Content |
|---|---|
| **Indledning** (hvem, hvorfra, hvad) | F.eks. *"40-årig mand henvist fra egen læge / otolog pga. [symptombeskrivelse]."* |
| **Dispositioner** | Anføres ved mistanke om bl.a. struma og hørenedsættelse |
| **Ekspositioner** | Anføres ved f.eks. mononukleose, hæshed, cancer, lydeksponering |
| **Allergi** | Såvel medikamentel allergi som atopier |
| **Tidligere** | Større indgreb samt kroniske sygdomme (hvornår, hvor, for hvad) |
| **Aktuelle** | Hovedsymptom: debuttidspunkt, akut/gradvist, ændring, behandling. Ledsagesymptomer: febrilia/infektioner? |
| **Øvrige organsystemer** | CNS-CP-GI-UG-BA: kort, relevant |
| **Medicin** | Præparatnavn, styrke, dosis |
| **Tobak/alkohol** | Hvad, hvor meget, debut |
| **Socialt** | Erhverv, civilstatus |

| Region | What to document |
|---|---|

| **\*Stemmegaffelprøver** | (document findings) |
| **N.facialis, SNBBB, fistelprøve** | Øresygdomme, svimmelhed |
| **Ansigtsskelet** | Ansigtstraumer, inkl. næsefraktur |
| **Bihuler** | Sinuitis, næse-allergi/polypper, cancer |
| **Ydre næse** | Skævhed, krepitation, løshed |
| **\*Rhinoscopia anterior** | Septum, pladsforhold, slimhinde, sekret |
| **\*Cavum oris** | Tandstatus, slimhinder, symmetri, pladsforhold |

| **Fiberlaryngoskopi** | Slimhinder, stemmebåndsbevægelighed, pladsforhold |

| **(Kranienerver)** | Hvis relevant |

\* = mandatory examination elements

## Hovedsymptoms organ og relaterede symptomer

The presenting complaint determines which symptom group to document in detail:

| Organ/system | Symptoms to document |
|---|---|
| **Ører** | Hørenedsættelse, smerter, flåd, tinnitus, klapfornemmelse, svimmelhed, facialisparese, catarrhalia, febrilia, traume |
| **Næse/bihuler** | Nedsat luftpassage (årstidsvariation), sekretion (årstidsvariation), mundrespiration, snorken, bihulesymptomer, tidl. næsetraume. Rødme over bihuler, smerter |
| **Cavum oris/spytkirtler** | Smerter, hævelse, sv.t. spytkirtler, relation til måltider/fødeemner, infektionssymptomer, glandelsvulst |
| **Ansigt** | Smerter (herunder neuralgiforme smerter), føleforstyrrelser, gab/bidefunktion |
| **Pharynx/larynx** | Ved mistanke om tonsillitis/pharyngitis: sengeleje, temperatur, side/midtlinjesmerter/otalgi, podning, behandling. Synke/respirationsproblemer, søvnproblemer, foetor ex ore, hæshed, stemmeforandring, hoste, glandelsvulst, bihulesymptomer, allergi |
| **Glandula thyreoidea** | Synke/respirationsproblemer, stemmeforandring, glandelsvulst, symptomer på ændret stofskifte — parastæsier, svedtendens, træthed, kardielle symptomer |
| **Ydre hals** | Hævelser (evt. størrelsesændring, vækst), lokale/meddelte smerter, hudforandring (rødme, ulceration, misfarvning). Samtidige symptomer fra 1-6 |
| **Oesophagus/bronkier** | Globulusfornemmelse, fejlsynkning, glandelsvulst, hævelser på halsen i øvrigt, smerter, synkestop, stemmeforandring, nakke-/skulder-/rygsmerter, hæmoptyse, vejrtrækning |

## Procedurespecifikke forløb

### Tonsillektomi / Tonsillotomi

| Term | Definition |
|---|---|
| Tons / Tonsillektomi | Fjernelse af mandlerne |
| Tonsillo / Tonsillotomi | Halvering af mandlerne |
| Re-blødning | Blødning efter fjernelse af mandlerne |
| H-opv | Forberedelse og Opvågning afsnit |
| NHH | Neuro-, hoved-, halskirurgisk sengeafsnit |
| Amb. | ØNH-ambulatoriet |
| Pt-hotel | Patienthotellet |
| OP | Operation / Operationsafdeling |

**Observation ved forundersøgelse:** respiration, smerter, ernæringstilstand.

**Postoperativ journalføring:**
- Tonsillektomi re-bløder overnatter på NHH til observation
- Ved re-blødning: journalfør tidspunkt, blødningskarakter (vævet/aktiv), behandling (konservativ / OP), og kontaktpersoner
- Postoperativt forløb: 14 dage fra operationsdato

**Pakkeforløb (hovedhalskræft):**
- Materiale sendes til histologi — journalfør prøvehåndtering
- Patient bookes til svar på MDT-spor (multidisciplinært team)

### Direkte laryngoskopi

| Term | Definition |
|---|---|
| OPV | Perioperativt afsnit — dagkirurgisk patient klargøres, observeres post-OP, hjemsendes herfra |
| NHH | Neuro-, hoved-, halskirurgisk sengeafsnit |
| LIN | Laryngeal Intraepitelial Neoplasi |
| T1A-glottiscancer | Tumor begrænset til ét stemmebånd |
| Endobase | Billede/video-lagringssystem for fiberskoper |
| Patoweb | Patologisk-anatomisk prøvesvars-system |
| DANHACA | Danish Head and Neck Cancer group |
| DANGLOT | Danish Glottic Cancer study |
| FON-LOG | Logopædisk henvisningssystem |

**Dokumentation ved forundersøgelse:**
1. Orientering i patientjournal
2. Identifikation af somatisk patient (ved både læge og sygeplejerske)
3. Læge dikterer og udfylder OP-tilmeldingsseddel ved operation

**Diagnostisk undersøgelse:**
- Fiberskopi, evt. med stroboskopi og/eller NBI lys
- Billeddokumentation via Endobase ved behov

**Peroperativt:**
- Materiale sendes til patoweb og evt. mikrobiologisk undersøgelse
- Journalfør prøvetagning og modtagelse

**Postoperativ kontrol:**
- Kontrol og svar på eventuel biopsi
- Histologisvar journalføres og patienten informeres
- Lægefaglig stillingtagen til talepædagogisk støtte
- Ved pakkeforløb: MDT-spor for samlet behandlingsplan
